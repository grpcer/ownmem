## Engineering memory entry point

- Before changing code or docs, run: `ownmem recall --memory-dir .ownmem -- <problem, path, or symbol>`.
- When asked to remember something, first decide whether a machine gate, project rule, canonical doc, temporary work package, or regression test owns it. Create long-term memory only if none fits.
- After a write, run: `ownmem audit --memory-dir .ownmem`. Never bypass schema, quota, or near-duplicate findings.
- For recent effectiveness, run: `ownmem report --since 7d`; Never claim accuracy without consumption or feedback evidence.
- Launch the local dashboard with `ownmem dashboard --open` when the dashboard layer is installed.
- Do not call external models and do not inject duplicate recall envelopes.
